CONTENT LOCK / 内容锁定地图

人物与关系人物增删、关系与行为动机

CURRENT PROTECTION / 当前保护她把伞留给了妹妹。

不新增人物动机，不改变关系与行为归因。

为什么锁定：这句同时交代两人的关系和行为归因；可以删掉重复解释，不能替换行为对象或补造动机。
EDIT PROPOSAL / 编辑提案审阅台

抽象片段 · 非真实作者文本

当前围绕“人物与关系”给出一组允许与阻断案例；点击上方锁定项可切换案例。

原稿

雨敲着屋檐。她把伞留给了妹妹。她想让妹妹一个人先走。

允许修改稿

雨敲着屋檐。她把伞留给了妹妹。

MECHANISM VERDICT / 机制裁决允许进入完整性审计只移除了重复说明，人物关系、行为和留白仍由原稿决定。

允许：有证据、未触碰锁定项的最小改动禁止：改变叙事事实或作者立场
FOUR-CORNER REVIEW / 四角独立复核

文风一致性是否仍符合已确认画像，是否被统一成平滑替代腔。

HEURISTIC GATE / 启发式风险门槛≤ 20不是 AI 比例；完整性失败仍然阻断。

另存修改稿保留原稿；文件名自动避让覆盖。

审计报告记录模式、画像、改动、四角复核、完整性与停止原因。

明确结论通过，或因内容保护而停止且未达启发式门槛。

BOUNDARY / 边界只处理文学文本；启发式风险分不代表真实 AI 参与比例或来源鉴定。视频仅展示用户确认公开的前后稿短摘录，不展示全文，也不宣称未提供的审计结论。
