SELECTED FIELD / 当前字段

招标金额

01 / 原文依据

预算、最高限价、控制价或招标控制价的明确表述。

02 / 提取规则

统一换算为人民币元；排除标书费、保证金、代理费和数量。

03 / 留空条件

金额语境不明或只出现费用、保证金时留空。

EXCEPTION LANE / 单条异常隔离

一条记录缺字段或解析失败保留索引与原因，进入异常清单

其余记录继续批次不因单条失败中断

DELIVERY GATE / 一致性验收

同一批次，两个格式，一份字段合同

行数一致CSV 与 JSON 来自同一去重结果。

固定 29 列列名与顺序满足字段合同。

金额单位为元数字字符串或空，不混入“万元”。

密钥不落盘API Key 仅在采集路径运行时使用。

CSVUTF-8-BOM，Excel 可直接打开。

JSONUTF-8、固定 29 字段，便于系统对接。

验收说明输入、去重、覆盖与异常缺口。

API Key 只在采集路径运行时使用，不写入脚本、输出或页面。

ACTIVE STAGE / 03 OF 06

金额与结果边界

分清预算、费用、数量与公告类型。

CURRENT FOCUS / 当前观察招标金额 · 本地文件
WHY IT EXISTS / 为什么需要

金额和中标结果是最容易被误识别、也最影响后续筛选的字段。

MECHANISM / 实际机制
  1. 01

    仅接受预算、最高限价与控制价语境。

  2. 02

    统一换算为元并排除费用、保证金与数量。

  3. 03

    先识别公告类型，再允许写入结果字段。

AUDIT TRAIL / 留下的证据
字段留空原因
说明金额或结果为何未提取
DECISION / 继续或停止

语境不足时留空；招标公告不产生中标结论。
