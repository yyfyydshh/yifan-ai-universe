# 项目说明视频共创清单

## 已锁定边界

- 页面里的工作流讲解动效负责解释 Skill 的结构、质量门和交付分支。
- 项目视频负责用一个已确认案例展示 Agent 对话、关键判断与真实结果；二者不得互相替代。
- 未进入共创的项目继续保持 `replace-later`。全球舆情分析项目已于 2026-08-15 进入分镜共创阶段；分镜确认前不接入成片。
- 只有用户与 Codex 共同确认案例后，才进入 HyperFrames 制作流程。

每个项目开始制作前，一起确认以下内容：

- Skill 的公开地址或可运行入口；
- 允许展示的输入，是否需要脱敏；
- 访问者点击项目后最应该看懂的一个能力；
- Agent 对话中必须出现的判断，不只是工具调用；
- 真实输出与证据位置；
- 视频长度、是否配音，以及无声观看时的字幕；
- 案例标签：真实、脱敏或模拟；
- 哪些信息明确不能公开。

确认后共同产出：案例事实卡 → 按项目时长生成分镜 → Agent 对话脚本 → 证据落点 → 脱敏审查 → 无声字幕版 → 视频成片。

视频与文章独立管理。视频素材放入 `public/demos/<project-slug>/`，不修改项目页的信息结构。
