# 去 AI 味项目介绍 · 2026-10-07

`/work/humanizer` 采用整站的奶油纸色、草绿、木色和 2D 卡通人物，不添加完整房间场景。主画面是一张可操作的手稿，人物读稿、保护原句、完成后示意；小牛随状态变化，也可以点击互动。淡色地面、植物线条、纸夹和卡通橡皮使背景不空。

## 默认交互

- 留白、对白、结尾三个固定原创文学片段，各自有明确的临时文风方向、保护句和多余解释。
- 点击橡皮、点击高亮句，或把橡皮拖到高亮句上，示意一次局部编辑。拖到其他地方不改文本。
- 点击带锁的原句，解释为什么不能改变意象、人物对白或开放结局，不修改任何受保护文本。
- 修改过程只划去对应解释；手稿与人物落点不随文字切换变化。
- 编辑后才开启对照入口。原稿与修改稿通过原生 dialog 展示，Escape 关闭，焦点回到入口。
- 切换片段或还原，清空修改、保护反馈、猫状态和对照窗口；不覆盖原稿。

## 事实边界

这是项目能力的固定演示，不运行在线改稿或 AI 来源鉴定。示例不是用户稿件，不宣称真实稿件通过了完整性审计或四角复核。

仓库 README 是简要说明的依据：只面向文学文本；先确认文风画像与保护项，再最小编辑；恒稳模式至少三篇作者确认的相近代表作；单篇采用临时画像；完整性审计与四角复核后另存改稿和审计报告。完整机制、视频、GitHub 出口保持在既有页面入口下可访问。
