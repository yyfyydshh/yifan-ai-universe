# v5 参考图审查｜第一批项目证据档案

状态：用户已确认并要求开始开发；参考图已不可覆盖地锁定到 `references/locked/v5/`。

## 共用检查

- 三张图均遵循现有近黑蓝、暖白、低饱和紫、中文 serif display、mono operational label 和细规则线体系。
- 每张图均为 `C0 code-only`：最终文字、控制、路径、矩阵、图标和交互全部由 React/CSS/SVG 实现；参考图不会进入生产页面。
- 三张图采用不同的真实信息结构：事实账本与单线路由、三路径汇流与双门验收、四轴适用性矩阵与阻断链。
- 绿色和红色均只表达规则分支；页面必须继续显示“机制演示，非当前运行状态”。
- 生成过程中发现并移除了 Sales 的虚构分类计数，以及监管页的虚构任务 ID、日期、记录数和哈希值。
- 不包含客户名称、公司名称、实时 Agent 状态、假计时、假商业指标或未确认案例。

## 01 Sales Copilot｜事实判断与方案路由台

参考：`references/locked/v5/01-sales-decision-routing.png`

- 三秒信息：零散销售信息被分为事实、假设和未知；信息不足时系统转为关键追问，不生成评分或画像。
- 主焦点：信息充分与信息不足的规则分支。
- 个人证据：事实分层、聚焦方案方向、核验材料、跟进草稿和人工外发边界。
- 阅读路径：摘要 → 事实账本 → 七阶段路由 → 规则分支 → 深度解释 → 交付物与边界。
- 留白职责：中央分支区为路径变化与状态切换提供 motion runway；没有固定高度死空白。
- 可实施性：左、中、右可用 grid 明确分区；移动端可按账本、路由、详情顺序重排。
- 内容风险：MQL A—D、JSON 契约、子 Skill 编排必须继续标记为“内部能力（项目陈述）”，不能伪装成公开仓库细节。
- 结论：`pass for user review`。

## 02 Mintlify 文档站｜三路径交付控制台

参考：`references/locked/v5/02-docs-three-route-console.png`

- 三秒信息：三类文档任务具有不同生产路径，但统一收束到线上验收与受控发布。
- 主焦点：`本地验证 ≠ 托管验收` 的双门结构。
- 个人证据：信息架构、HTML 转 MDX、图片本地化、链接与重定向、导航搜索、托管验收和发布授权。
- 阅读路径：真实经历/公开 SOP → 路径选择 → 三路工作流 → 双门 → 交付物与授权边界。
- 语义图形：三路代表从零、迁移、维护；汇流代表共享质量规则；双门代表环境不同，不能互相替代。
- 可实施性：三路可由结构化数据驱动；移动端只展示所选路径，其他路径保留为可访问 tab。
- 内容风险：公开仓库只能称为可复用 SOP；八爪鱼生产项目的事实来源是简历与项目陈述。
- 结论：`pass for user review`。

## 03 金融监管监测｜企业适用性审阅台

参考：`references/locked/v5/03-regulatory-applicability-desk.png`

- 三秒信息：记录必须通过批次证明、全文审阅、四轴适用性、证据覆盖和报告校验，才可能进入报告与受控投递。
- 主焦点：地域、监管主体、业务活动、时间条件四轴适用性矩阵。
- 个人证据：run manifest、evidence index、review ledger、analysis、HTML 报告与投递防重指纹。
- 阅读路径：输入与角色 → 八阶段证据轨道 → 适用性矩阵 → 阻断分支 → 深度说明 → 批次字段与防重。
- 语义图形：矩阵编码真实适用性条件；红色分支编码缺少全文审阅、覆盖缺口、报告失败和重复投递；不是风险等级仪表盘。
- 可实施性：矩阵和分支均可用 HTML/CSS/SVG；移动端将四轴转为四行，保留所有阻断原因。
- 内容风险：处罚记录只能表示监管关注；不能推导目标企业已经违法，报告也不能被描述为法律意见。
- 结论：`pass for user review`。

## 一致性、节奏与 Hallmark 审查

- 一致性：三张图共享色板、字体角色、icon 线性语言、边框密度和右侧深度解释规范。
- 变化范围：Sales 使用左账本/中分支/右解释；Docs 使用三路汇流/双门/右验收；Regulatory 使用证据轨道/中心矩阵/右解释，未复用同一大卡片模板。
- Grey-block test：移除图标后，三页仍能通过账本、轨道、矩阵、汇流和分支关系保持辨识度。
- Slop 风险：无随机 glow、无卡片墙、无无意义轨道、无假 KPI；状态 label 均承担流程解释职责。
- 参考图文字仅用于锁定层级和内容位置；最终实现使用已核验的代码文案，允许修正图片生成造成的个别字形问题。
