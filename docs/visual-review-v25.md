# 视觉审查与调整 · 2026-09-07

本轮以用户最后的判断为准：星球是一种概念，不能让网站变成天体模型。审查以本地项目源码、现有内容及生产构建截图为依据；线上站点未发布更新。

## 主要判断

网站最有价值的内容是个人身份、七个可进入的项目和实际交付证据。写实星球虽然显眼，却让访客先看材质、后找项目，削弱了个人作品集的识别。视觉重点应落在姓名、项目标题、可验证的内容，空间关系承担辨识度。

| 位置 | 问题与判断 | 本轮处理 |
| --- | --- | --- |
| 首页首屏 | 定位、人物、项目与装饰争夺注意力 | 放大姓名层级，统一暖白主行动，用人物亮度与背光控制主次，保留实体遮挡 |
| 项目入口 | 实体球面成为主角，远处项目文字难读 | 移除地表、土星环和多彩球体，改为透明光场与细弧线，提高文字可见度 |
| 作品页 | 过度依赖球体辨识，概念压过内容 | 保留空间浏览和拖动，突出项目名称及进入提示；说明文字采用更自然的换行 |
| 动态 | 持续巡航不利于停留阅读 | 添加暂停与继续，保留键盘导航及减少动态偏好 |
| 移动端 | 桌面空间布局不适合窄屏信息检索 | 改为开放式项目行，直接展示名称、简介和入口 |
| 交付数据 | 数字从零增长、外框偏重 | 真实数值立即呈现，用细分隔线组织证据 |
| 分类统计 | 写死的分类数与现有项目不一致 | 从项目数据生成：核心系统 3、专业 Skill 4 |
| 页面节奏 | 首页末段留白占据过多高度 | 收紧末段间距，保持内容层级 |

## 后续视觉方向

背景交互落地：仅首页与 `/work` 挂载 `InteractiveStarfield`。固定、不规则的星点与细弧线通过局部软遮罩显现；鼠标静止时附近保持微亮，旧位置约 1 秒内淡出，底层星尘轻微视差。文字区域降低装饰亮度。触屏与减少动态偏好自动停用交互；闲置、页面隐藏和卸载时停止绘制并清理事件。以实际 Canvas 像素检查局部显现、远处不亮、停留和淡出行为，并检查其他页面未挂载。

背景交互增强：增加约 460ms 流星尾迹、十字星光标及链接圆环反馈；加亮局部星图。滚动以缓动驱动两层星尘位移并修正鼠标在背景中的坐标。只响应原生鼠标与滚动事件，不阻止默认行为；离开区域、切换路由或减少动态模式时清理光标。截图见 `qa/spatial/home-meteor.png`、`work-meteor.png` 与对应 `*-scroll.png`。

2026-09-07 用户复核后修正：首页人物恢复位于轨道前后层之间；整个前半圈经过身前，后半圈被人物轮廓遮挡，悬停不再把后方项目提升到身前。人物显隐使用亮度，保持基础图层不透明；新增随鼠标位置变化的柔光与前景文字暗色衬底。补充整圈 30 个位置、悬停、键盘聚焦和拖动的回归检查。

同日对比度复核：按照修改前 `globals.css` 的项目渐变色恢复完整深色底，去掉透明渐隐、文字灰化和模糊暗斑。项目保持不透明，入口文字恢复高亮。人物默认亮度从 0.3 降至 0.1，触发图层亮度从 0.6 恢复至 0.82，项目悬停时维持 0.85 的显现强度，确保触发前后有明确差异。对照截图分别为 `qa/spatial/portrait-idle.png` 与 `qa/spatial/portrait-revealed.png`；新增移入、项目悬停、移出检查。

- 项目详情：保持各项目真实工作台作为主要视觉素材。若继续精修，应优先统一演示封面与关键结果的展示尺度，避免增加装饰球体。
- 经历与关于我：用真实时间线、角色关系与证据组织页面，延续同一字体和留白体系。
- 思考与文章：阅读清晰度优先，空间装饰应停留在背景。
- 从访客判断角度，视觉应帮助回答“你是谁、做过什么、如何验证”。本轮不新增未经核验的业绩或宣传结论，也未用转化数据证明主观设计判断。
