## Style fingerprint

- 世界：沿用 AI Capability Universe 的深色证据档案，不改变全站主题。
- 背景：近黑石墨 `#070A12` 与非常克制的紫色空间雾，不使用大面积发光渐变。
- 文字：暖象牙 serif 承担主张和答案标题；中性 sans 承担客户原话与解释；mono 只用于少量证据状态。
- 几何：一像素规则线、低圆角或直角、无玻璃卡片、无假浏览器/终端 chrome。
- 强调：低饱和紫色只表示当前可选答案和被引用原话；绿色只表示规则条件已满足，参考图不展示假运行通过状态。
- 图标：只在四项答案旁使用克制语义图标，不建立 icon wall。

## Section render contract

- `THREE_SECOND_MESSAGE`：把客户的一段话，变成销售下一步该做的事。
- `PRIMARY_FOCAL_POINT`：右侧“销售专业助手给出的答案”，左侧原话作为直接证据。
- `AUTHORED_MOVE`：选中“建议这样问”时，左侧对应未知项与销售追问被同一条细证据路径关联。
- `READING_PATH`：标题 → 客户原话 → 四项答案 → 可靠性边界。
- `C0 code-only`：最终文字、图标、连线、选择状态和情境切换全部由 DOM/CSS 实现；参考图只作为构建目标，不进入生产资产。

## 构图

1. 顶部为紧凑项目定义：
   - 眉题：`SALES COPILOT / 销售专业助手`
   - 标题：`把客户的一段话，变成销售下一步该做的事。`
   - 一句输入/输出说明和一句角色边界。
2. 主体为 42% / 58% 的前后对照：
   - 左侧“客户原话”：三句脱敏机制示例，当前引用片段被标出。
   - 右侧“销售专业助手给出的答案”：客户当前的问题、还需要确认、建议下一步、建议这样问。
   - 当前选中“建议这样问”，其下显示一句普通语言依据。
3. 两栏之间只保留一条短证据路径，不放独立“可靠性检查”栏。
4. 底部为一条可靠性带：只引用原话 / 推测单独标记 / 信息不足先追问 / 外发由销售确认。
5. 右上角保留次要情境开关：`已有足够信息 / 还缺关键信息`，但不比标题或答案更抢眼。

## 内容和证据边界

- 所有对话写明“脱敏机制示例，不代表真实客户记录”。
- 首屏不出现 MQL A—D、JSON 契约、子 Skill 编排或白名单术语。
- 不展示假客户公司名、金额、转化率、运行状态、实时 Agent 或自动发送状态。
- 外发内容明确为“建议话术 / 可编辑草稿”。
- 公开仓库支持页面的产品边界；内部实现事实只在下方第二层呈现。

## 响应式与可复刻性

- 横向参考图为桌面 section 截图，不是整页海报或多屏拼贴。
- 桌面：两栏同处首屏；主结果完整显示。
- 移动：转为单列，客户原话紧接四项答案；证据路径改为每项下方的来源标签，不绘制跨栏线。
- 所有代码文案保留安全区，参考图不得依赖烘焙的最终文字或不可分离的 raster UI。
- 无新增 production raster 素材。

## 四向审查标准

- 视觉意义：不读说明也能说出“客户说话，助手告诉销售下一步”。
- 一致性：与 v6 共用深石墨、暖 serif、紫色焦点、细规则线；不改变全站身份。
- 单调性：通过前后对照和证据回指形成作者性动作，不使用三栏流程或卡片墙。
- 可实施性：所有元素可由 React/CSS 重构；没有跨边界阴影、烘焙文本或不可响应式重排的视觉。
