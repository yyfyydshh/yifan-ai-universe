# World v2 生产图片规范

使用内置 image_gen 生成与编辑，未调用外部图像 API。生产文件在 `public/world/`，尺寸、来源和哈希见 `world-assets.json`；原图保留在 `references/drafts/world-v2/`，人物已确认稿位于 world-v1 草稿目录。

共同提示要求：成年青年卡通，白 T 恤、橄榄色工装裤、短黑发、项链；保留已确认人物辨识特征。轮廓清楚，内部线条较轻，少量平涂明暗，大片叶丛、简化石面、木色与草木绿。透视与左上方光源一致，避免写实碎叶、复杂肌理、幼儿比例和亮蓝玻璃按钮。所有正式文字由网页绘制。

| 素材 | 提示内容与保留条件 |
|---|---|
| 人物 look 状态 | 以已确认坐姿为编辑源，只调整视线看向访客；服装、头型、身形、手脚、画布与落点保持一致 |
| 猫 idle / awake | 奶牛花纹、蜷卧轮廓、尾巴和接触点固定；awake 只睁眼；透明底 |

设计参考在 `references/locked/world-v2/`。首页和手机稿统一上述成年卡通风格；project-interactive-design 提供卡通工具桌、三步物件与纸面模拟区域的参考；阅读稿保留约 760px 正文栏和目录，用奶油白、深蓝绿文字及草木绿提示。参考图中的示例正文不迁入正式页面。

新增生产素材：tour-computer 为奶油绿的小电脑，tour-notebook 为有分栏与勾选标记的翻开手册。工作室七个独立物件分别为地球仪与资料、对话气泡、文档册、盾牌与检查单、公告整理机、新闻收音机、笔与修订本；沿用同一透视、木色、草木绿、简洁卡通线条和透明底，无烘焙文字。最终均以 800px WebP 输出，原始 PNG 保留。纸飞机、骰子、灵感罐与信箱属于 code-native 矢量控件，与地图热区同步；这些控件没有冒充生成素材。

## 最终空间修订

- sky-v3 / sky-night-v3：远处增加浮岛、城堡、天文台和分层云；保留左上文字低密度区域，昼夜保持远景位置关系。
- island-v5：增加花、垂藤、石阶、灯笼、瀑布和桥索；中央人物脚与猫的前沿保留平坦草地。仅清除发生穿插的栏杆，保留上层岩柱、木橋连接点及七区承托位置。失败的 v4 丢失上层岩柱，未投入生产。
- studio-room：同一成人卡通世界的木屋室内，正面略俯视，窗外浮岛；左右长桌、中央书桌、前低桌、圆桌和两侧墙架形成完整空间。工具落点处留白，家具和固定装饰合并在完整背景中。
- studio-notebook-flat：以原修订本为参考，改为平摊在桌面上的薄本，斜视可见页厚，钢笔沿书页放置。保留原生 800:533 比例，不用 CSS 三维变形伪造透视；只替换房间书本，电脑窗口仍保留原图标。

相机与风铃为网页矢量组件；拍照生成的插画明信片在浏览器内组合现有素材，不上传照片或调用真实拍摄设备。

## 最新修订：连续底板与统一密度

上述独立岛面和房间叠图方案保留作过程记录，正式场景已更新：

- `world-scene-open`：以七区位置与已确认卡通人设为参考，重绘完整建筑、草地、岩柱、台阶，清楚轮廓、大片平涂、减少石头肌理。中央留角色落点，移除外围绳索和平台栏杆，保留木桥板面与家具。请求大尺寸后实际返回1536×1024，记录原生尺寸，不假称高分辨率。透明底、无角色、无烘焙文字。
- `studio-room-integrated`：以空房参考编辑，把档案、地球、电话、收音机、打印机、书和小天平、平摊本、电脑键鼠与座椅直接画入房间。普通生活物件，无对话气泡/盾牌贴纸；承托、视角和遮挡在同一图中解决。
- `yifan-wave`：以确认人物原图编辑，保留成年感、服装、画布比例与脚落点，抬一只手招呼，不改变坐姿。
- `cat-stretch`：保留奶牛花纹与猫的体积，在原画布内向前伸爪，保持地面接触。
- 六张 `*-scene-*` 为桌面机械导出：人物389×389、猫197×197，无损WebP，与1536×1024主场景的0.96纹素/逻辑单位一致；原PNG和800px独立肖像保留。软件Canvas中使用原生底板像素，不经过1600宽的中间放大。

最新锁定参考另存 `world-scene-open-design.png`、`studio-room-integrated-design.png`，未覆盖旧版设计。
