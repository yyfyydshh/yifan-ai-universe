# 参考图生成计划 v4 — 全球舆情项目证据档案

## 变更范围

本版本只重构“全球舆情与品牌口碑分析 Skill”的项目详情下文讲解样板，不改变全站导航、项目 URL、深空色板、字体家族和作品宇宙交互。目标是把现有六章抽象观测台收束为招聘方可以快速阅读、可以沿仓库证据复核的工作流讲解动效。

## 事实锁定

- 典型输入：分析主题、时间范围、目标有效数据量、市场 / 语言、竞品和关注维度。
- 主工作流：只读连接器检查 → 主题范围门禁 → 来源策略与采集 → 清洗、去重与来源审计 → 正式报告门槛 → 多格式交付。
- 正式报告门槛：至少 100 条有效记录、5 个来源域名、2 种来源类型，并通过来源策略审计。
- 未达到门槛：不包装成正式结论，只交付数据包、覆盖缺口与续采建议。
- 真实交付：候选预览、六工作表 Excel、Markdown 报告；用户明确需要时生成离线 HTML。
- 主题边界：不适用于政治、战争、军事、武器或情报主题。
- 角色表述：工作流设计、证据门槛、报告交付；不添加仓库未证明的虚构指标、客户名称或商业结果。

## Style fingerprint

- 世界观：深空能力档案；深空只提供安静的空间底色，信息结构由真实证据关系产生。
- 色彩：近黑蓝纸面、暖白文字、低饱和紫焦点；绿色只用于已通过的真实质量门。
- 字体：中文 serif display + sans body + mono evidence labels；标题 roman，不使用渐变文字。
- 几何：细规则线、开放式分区、一条主证据链；不使用随机点阵、玻璃卡片墙、球体仪表盘和装饰性轨道。
- 密度：首屏可在 30 秒内读完定位、输入、角色、主流程、门槛与交付物。
- 动效语言：路径推进、状态切换、一次性揭示；后续实现每屏不超过三种动效原语。

## Section render contract — Evidence overview anchor

- `SECTION`: global-opinion-evidence-overview
- `RESPONSIBILITY`: 在单个桌面视口内说明项目解决什么、如何工作、在哪里停下，以及最终交付什么。
- `THREE_SECOND_MESSAGE`: 这是一个把公开网页数据转化为可审计 VOC / 事件声誉判断的真实 Skill，而不是一个装饰性数据大屏。
- `PERSONAL_EVIDENCE`: 真实输入字段、只读采集、来源审计、100 / 5 / 2 正式报告门槛、Excel / Markdown / HTML 交付与明确主题边界。
- `AUTHORED_MOVE`: 用一条“范围 → 采集 → 审计 → 质量门 → 交付”的水平证据链替代六张抽象观测图；质量门下方直接写出达到与未达到时的分流结果。
- `PRIMARY_FOCAL_POINT`: 正式报告质量门及其 100 / 5 / 2 三个门槛。
- `SECONDARY_ANCHORS`: 左侧 30 秒摘要；右侧真实交付物堆栈与紧凑视频入口。
- `READING_PATH`: 项目标题 → 一句话定位 → 典型输入 / 我的角色 → 主工作流 → 正式报告门槛 → 交付物与边界。
- `WHITESPACE_MAP`: 标题与摘要周围保留呼吸；工作流节点之间使用开放路径；右下留白承接后续关键判断章节。
- `SEMANTIC_GRAPHIC`: 线表示数据和证据沿真实步骤推进；门表示能否发布正式结论；分支表示降级交付，不表示失败动画。
- `OVERLAP_LEDGER`: 不允许任何节点、标签、数字或 CTA 重叠；背景星点不得进入文字闭合区。
- `EXCLUSION_ZONES`: 导航、标题、每个流程标签、门槛数字、交付物名称和视频入口。
- `VIEWPORT_PAYLOAD`: 1440 / 1920px 首屏完整出现标题、30 秒摘要、整条工作流、三项门槛和三种主要交付物；移动端改为单列顺序，不依赖横向滚动。
- `ARCHETYPE`: C0 code-only；参考图只作为布局与层级基线，不进入生产代码。
- `TOPOLOGY`: section-specific；其余六项目共享阅读骨架，但必须使用各自真实流程、门槛和交付图形。
- `PANEL_BUDGET`: 最多一个轻边界的摘要区、一个质量门区域和一个交付物区域；不形成等尺寸卡片墙。
- `CODE_SAFE_AREA`: 所有文字、图标、路径和状态由 React / CSS / SVG 实现。
- `FORBIDDEN`: 假 KPI、情绪占比仪表盘、随机噪声点、无语义球体、六个重复章节卡片、不可验证的实时状态、把不足样本写成正式分析结论。

## 参考图目标

生成一张独立 16:9 横向网页参考图，覆盖项目详情下文的工作流讲解 section。沿用现有站点 chrome 和品牌语气，但明显降低装饰密度、提高正文对比度与分组清晰度。参考图中的文字用于确认层级和阅读路径，最终实现保持为可编辑 live text。视频演示属于独立媒体槽，不由本参考图定义内容。

## 恢复边界

本轮不覆盖 `references/locked/v3/`。候选图写入 `references/candidates/v4/`，只有在用户确认参考图、确认素材拆分和确认执行简报后，才允许锁入 `references/locked/v4/` 并修改详情页代码。
