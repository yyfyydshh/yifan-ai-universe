- 交互边界：使用原生 React、CSS、`IntersectionObserver`、`ResizeObserver` 与 `requestAnimationFrame`；不使用 WebGL、自定义光标或装饰性视差。

### Meaning contract

- `THREE_SECOND_MESSAGE`：这个项目不是一个静态说明页；招聘方能看到 AI Skill 的判断与工具流程如何被逐段观察。
- `PERSONAL_EVIDENCE`：六个真实 Sales Copilot 工作流节点，以及事实 / 假设 / 未知分层、白名单链接等既有可靠性边界。
- `AUTHORED_MOVE`：滚动章节驱动左侧观测台改变视觉模型；不同能力不再复用同一张卡片。
- `PRIMARY_FOCAL_POINT`：左侧由六个真实节点组成的激活工作流，信号停在当前第三节点。
- `SECONDARY_ANCHORS`：右侧当前章节文字；远端的 01—06 章节索引。
- `READING_PATH`：激活工作流 → 当前章节标题与结论 → 下一个章节提示。
- `WHITESPACE_MAP`：左侧节点之间的空域是信号移动跑道；两栏中缝是阅读停顿；右侧段落下方留白指向下一章节。
- `SEMANTIC_GRAPHIC`：节点顺序表示 Sales Copilot 的实际处理阶段；连线表示信号传递；亮度只表示当前章节，不代表实时运行或完成率。
- `OVERLAP_LEDGER`：轨迹可穿过低对比星点背景，但不得进入节点标签、正文或章节索引的闭合区域；无语义主体互相遮挡。
- `EXCLUSION_ZONES`：所有节点名称、正文段落、章节编号、焦点环各自为闭合安全区；任何星轨、辉光与分隔线不得穿越。
- `VIEWPORT_PAYLOAD`：桌面首屏完整显示当前场景、章节标题和至少一个上下文提示；移动端取消 sticky，场景缩为当前章节上方的静态小型图。

### 拓扑与预算

- Archetype：`C0 code-only`。
- 代码负责：全部文字、Lucide 图标、节点、路径、状态、章节观察、键盘/滚动行为和响应式 reflow。
- 图像负责：无 section 专属 raster；深空星点是可复用的 code-native 背景。
- 主 anchor：左侧开放式观测台。
- 次 anchor：右侧叙事与远端章节索引。
- Panel 预算：0 个独立图像 panel；最多 1 个轻薄的当前章节文字面，不形成卡片墙。
- 禁止融合：导航、项目标题、正文、标签、节点名称、进度与状态不能烘焙进背景。

### 响应式与交互假设

- 桌面：最大宽度约 `84rem`；左侧约 `30rem` sticky 观测台，右侧约 `34rem` 六段叙事。
- 移动：单列，取消 sticky；每段叙事上方携带自己的静态语义图。
- `IntersectionObserver` 只激活当前章节；非当前场景保持安静。
- reduced-motion：不做路径位移与章节淡入，直接展示清晰的激活状态。
