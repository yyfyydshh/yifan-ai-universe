## 必须调整的几何

以下坐标以1600×1120研究稿为基准，均为视觉估计，便于定位，不是代码中的已验证精确坐标。

### 1. 收拢态存在大块天空通道

**位置：中央岛左上、左下及右下；尤其工作室—中央、思考山丘—中央、中央—杂物间之间。**

工作室大致位于x260–595/y320–690，中央岛约x575–1085/y550–825。两者的草地面高度相差较大，中间以天空和零散踏石相隔，仍读成两个独立悬浮图标。思考山丘位于x255–560/y700–1020，中央岛与其之间是长而竖直的天空通道。右下杂物间约x1225–1470/y650–900，也与中央主体脱离。只有放映室贴在中央岛右缘，紧密程度不均衡。

原图的核心不是“七座小岛围着人物”：它有较高的写作/声音平台、左右中层场所、较大的中央草地，以及向左下和右下延伸的低台阶。草地和岩体共同提供连续的大轮廓，建筑自然嵌在不同高度上。

建议先完成**没有踏石的收拢布局**：

- 工作室向中央收近，并略向下，使其可行走边缘与中央草地左后侧形成短连接。
- 思考山丘向右上收近，作为左下低台，避免单独悬在画面下角。
- 游戏桌向左收近到声音房右下方，保留中层高差。
- 杂物间向左上收近，接在中央/放映区右下侧。
- 写作与声音保留高位，但收窄二者间距，并明确各自通向中央后沿的层级关系。

不要仅把所有物件整体放大：那会先让人物、标牌和房屋互相盖住。应按相邻草地边缘重排，保留高差，在岩体与植被上形成有前后关系的视觉连贯。可把收拢态的相邻可走边缘间隙先控制在约10–30px这一量级，再按石阶尺寸校准；这只是初始几何建议，最终以实际图像为准。默认状态应读成紧密的一个整体，展开态再显著拉开距离。

### 2. 踏石当前没有构成可走的路径

**位置与问题：**

- 写作小屋至工作室附近的斜向石串，约x500–625/y335–490：起止点不接草地，更像沿天空排列的小石块。
- 工作室至中央左侧，约x585–610/y575–620：石块在岩壁侧方，与工作室草地面及中央草地入口都没有明确对接。
- 中央至思考山丘，约x575–595/y705–860：长串近乎垂直，第一块接近中央正面岩壁，最后一块也没有清楚落到思考平台草地。
- 声音房至游戏桌，约x1130–1160/y355–460，以及放映/杂物间间约x1210/y675–750：仍有“石串经过空中，但不知从哪里上、在哪里下”的问题。

建议只保留具有明确目的地的少量连接。每条路径先标定起点和终点的**草地接触面**，再用两三块有透视与高度递进的台阶连接。第一块应出现在上方平台边缘之外，最后一块应落到下方平台可行走处；不能从岩壁正面起步。若需要长串五六块石头才能跨过当前空隙，应先收近岛屿，不靠增加踏石掩盖松散布局。

高位写作与声音之间可保留原图的短桥关系，但桥面必须对接两个平台的地面高程。不要为每一对邻居都画连接，否则会变成环形路线图。独立刚性小幅浮动的动效容差留待实现阶段核验，不能让路径端点随着动画穿进岩壁。

### 3. 顶部横石碰到人物发顶

**位置：约x785–883/y305–332，写作与声音之间、人物头顶正上方。**

三块横向踏石与黑发轮廓相切，像压在头发上的附件；同时石串没有接到两端岛的地面。这里是人物焦点周围应保持清楚的区域。

建议把该连接改到人物后方更高的位置，并在发顶与连接下缘之间保留明确的天空间隔；或结合两个高台收拢后，用短桥替代。不要仅减小石块，它们的落点与路径含义仍需成立。

### 4. 放映室和杂物间的建筑尺度偏小

**位置：中央右侧放映室约x1010–1225/y465–700；右下杂物间约x1225–1470/y650–900。**

放映小屋的屋顶、门廊及座椅相对工作室明显缩小，而名称牌和猫的视觉重量较大，看起来像人物旁边的一枚小图标。原图中各建筑处在同一个可使用世界，虽有远近，但没有如此强的微缩差。

建议优先按门口、椅子和台阶的尺寸校准，而不是只比较整张透明PNG宽度。放映室可先尝试约1.2–1.3倍的建筑视觉尺度，再把平台向右侧整理，避免增大后压猫；杂物间可随相邻平台收拢适度加强。应保持人物焦点，不必让七座屋子的像素宽度完全相同。增大后要重新核对标牌、猫前爪和中央草地边缘。

## 本张可保留的部分

人物与猫的形象和当前脚底/腹部承托可以保留。天空、远景和左上标题区给出了足够留白；七个场所的语义也能辨认。各岛作为独立刚性单元的素材方向可行，问题主要在默认位置、建筑相对尺度和连接落点。

这里的pass不意味着参考已可直接锁定。必须先修正收拢构图与连接，再查看新的完整研究图。后续还需要至少一张真正展开态、一张选中岛居中并显示介绍的构图，以及七种人物/猫动作的接触证据；它们不能由这张静态收拢研究图代替。
