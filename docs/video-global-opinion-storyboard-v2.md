# 全球舆情分析项目视频 · v2 中文 Agent 对话分镜

状态：`draft / awaiting user confirmation`

## 最高优先级：对话即能力证据

- Agent 对话是视频的主画面、主叙事和主要能力证明，不把真正的信息藏在旁白或字幕里。
- Agent 的每一条关键回复都必须带有可读的结构化内容：连接回执、能力清单、任务理解、执行进度、候选预览、来源审计、质量门结果或交付文件。
- 右侧视觉不再是与聊天分离的抽象仪表盘，而是当前 Agent 消息展开出的“消息附件 / 结果视图”。观众即使关闭字幕，也能从对话和附件完整理解 Skill 做了什么。
- 字幕只承担三件事：标记阶段、补充时间流逝、声明案例与数据边界；字幕不得新增能力、结论或指标。
- 画面信息优先级固定为：`Agent 中文回复 > 回复内的证据附件 > 用户输入 > 辅助字幕 > 装饰动效`。
- 关键中文对白、数字、文件名和状态必须 code-native，不能烘焙在概念图里，也不能使用英文占位词。

### Agent 回复的固定结构

1. 一句明确判断：现在理解了什么、完成了什么或是否达到门槛。
2. 一块可视证据：参数、来源、记录、候选结果、审计门槛或文件清单。
3. 一个下一步：继续运行、等待补采、请求确认或打开交付物。

这三层必须出现在同一条 Agent 回复中，避免只显示“正在处理”或让字幕代替结果。

## v2 的核心变化

- 第 2—7 帧使用持续存在的“双层 Agent 工作台”：左侧是中文对话，右侧是 Agent 回复展开出的 Skill 能力结果。
- 对话不是旁白字幕。用户与 Agent 的原句直接出现在界面中，并通过消息进入、逐字显现、回复状态和结果投射形成交互感。
- 右侧结果必须由当前 Agent 回复触发：连接、能力清单、范围解析、候选预览、质量门禁、文件交付和 HTML 分支不能独立悬浮。
- 草稿参考图中的英文与自动生成中文全部无效；最终实现只使用本文件锁定的中文。

## 交互与酷炫感的实现边界

- 消息不是普通气泡：每条消息锚定在左侧信号脊柱上，当前 Agent 回复以紫色规则线投射到右侧结果。
- Agent 打字只用于短句，长能力说明以结构化条目快速展开，保证 25 秒内可读。
- 结果揭示采用三种动效：信号路径推进、状态交叉淡入、文件/报告位移组装。
- 发光只标记当前执行点；绿色只在连接成功、门槛通过和文件完成时出现。
- 每次 Agent 回复都必须产生可见的 Skill 能力证据，不能只返回“正在处理”。
- 无旁白环境下，所有关键对话必须直接可读；另提供中文 VTT 作为无障碍字幕。
