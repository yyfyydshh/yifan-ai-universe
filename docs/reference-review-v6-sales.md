# Sales Copilot v6 参考与实现审查

锁定参考：`references/locked/v6/01-sales-professional-assistant-workbench.png`

## 参考结论

- 项目身份从“跟进简报”修正为 `Sales Copilot / 销售专业助手`；简报不再承担项目定义。
- 三秒信息：它读取销售沟通和客户资料，协助销售理解客户、判断机会、匹配方案并明确下一步。
- 主焦点：具体的“客户判断与行动建议”，而不是 Agent 活跃状态或七阶段流程图。
- 语义图形：连接关系表示一项判断引用了哪句客户原话、通过了哪项可靠性检查。
- 空白：主工作台自然收口；深度说明独立位于下方，不再通过等高双列制造空白。
- 内容边界：公开仓库证明脱敏功能概要和人工控制边界；MQL A—D、严格 JSON 契约与子 Skill 编排继续标记为用户提供的内部项目事实。
- 素材结论：C0，0 个生产 raster。

## 实现审查

- 默认先展示完整能力，让招聘方立即看到项目用途；切换“信息不足”后，页面只返回关键追问。
- 点击“核心需求”等结果会同步点亮对应客户原话和可靠性检查；下方深度层提供为什么需要、实际机制、可核验产物与使用边界。
- 绿色只表示由事实或授权材料支持；紫色表示当前选择；“推断待核验”和“待确认”均显式标注。
- 示例对话明确标注为脱敏机制示例，不冒充真实客户记录。
- 320、375、390、414、768、960、1280、1440、1920px 均无水平溢出。
- 鼠标、焦点、方向键、信息充分 / 不足切换均已验证；控制台无页面错误。
- ESLint、TypeScript 与 Next.js production build 通过。

结论：`pass`。
