# v23 正式投递版参考与验收合同

## 采用基线

v23 不重新设计已确认的深空视觉和项目工作台，而是把当前稳定实现作为 adoption baseline。`references/locked/v23/` 中的页面基线记录收口前构图；工作台基线记录各项目默认状态；首页 Reveal 继续继承用户已确认的人物与单轴宇宙方向。

## 统一合同

- 桌面导航保留字标、五个页面名称和联系入口；嵌套路由必须归属对应一级导航，当前位置只用刻度和 ARIA 表达。
- `70rem` 以下使用可键盘操作的非模态导航面板，不隐藏一级页面。
- 联系入口必须在同一弹层中展示可扫码微信、邮箱和电话；二维码直出原图，不经过有损图片代理。
- 七个项目首屏必须同时说明任务入口、关键判断和交付结果；不新增未经证据支持的指标。
- 七个视频不挂载字幕轨；中文 Agent 对话、阶段与结果直接由画面表达，不重复装饰文字。
- 项目工作台保留各自语义结构；交互状态必须可由点击、键盘或聚焦改变，且不依赖在线 Agent。
- canonical、Open Graph、Twitter、sitemap、robots 与 Manifest 使用同一站点 URL 真相源。

## 响应式捕获

- Desktop：`1672 × 941`
- Ultrawide：`2200 × 1200`
- Mobile：`390 × 844`

每个 Identity section 使用一张 v23 adoption reference，以及三个正式捕获。捕获不得裁切一级标题、项目入口、工作台当前状态或移动导航的操作区域。

## 通过门槛

- 320、375、414、768、960、1280、1440、1920px 无横向滚动或标题裁切。
- 首页单轴人物宇宙的点击、6px 拖动阈值、惯性方向、键盘与 reduced-motion 不回退。
- 七个项目工作台均能产生至少一次可观察状态变化。
- 微信二维码、邮箱、电话、简历和 GitHub 出口真实可达。
- 7 个视频与 poster 存在且时间边界有效；舆情 Web 视频保持 1080p、H.264、`yuv420p` 与 faststart。
- ESLint、生产构建、Playwright smoke / release、媒体检查和 Identity verifier 全部通过。

## 回退边界

v23 只收口导航、联系弹层、元数据、项目首屏事实轨、媒体路径、自动化测试和 Identity 证据。首页人物素材、单轴公转数学、项目事实、文章正文、工作台语义和最终视频内容不在本轮重做范围。
