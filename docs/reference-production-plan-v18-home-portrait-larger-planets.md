## 本轮设计变化

- 四颗项目星球相对 v17 统一放大约 16%，不单独突出某一项目，保持同一项目层级。
- 三轴系统继续位于首屏右侧，整体投影半径略微收紧，让星球占据更多有效画面，减少轨道中心的大面积空洞。
- 保留前后景尺寸差与亮度差，维持 3D 空间感；放大不等于四颗星球排成规则网格。
- 星球安全区之间保持明确间隔；任何巡航、拖动与惯性状态都不得遮挡项目标题、图标或“查看项目”。
- 左侧真人窗口继续采用默认约 35% 透明度的身份投影；悬停 / 聚焦约 60%，点击后在原位置完整显影，再次点击收回。
- 不新增指标、说明卡、装饰文本或虚构状态；首页仍只表达身份、方法和四个代表项目。

## Render contract

- `THREE_SECOND_MESSAGE`：真实人物将业务问题封装为可运行、可验证、可复用的 AI 能力。
- `PRIMARY_FOCAL_POINT`：姓名与角色定位。
- `SECONDARY_ANCHORS`：真人身份窗口、三段方法 rail、放大的四项目三轴系统。
- `READING_PATH`：姓名 / 角色 → 真人与价值主张 → 方法 rail → CTA → 四项目证据。
- `SPATIAL_RULE`：右侧是紧凑但不拥挤的三轴体；星球沿三条不同倾角轨迹分布，并通过 scale、opacity 与 z-order 表达深度。
- `INTERACTION_RULE`：自动巡航、拖动改向、松手惯性与沿用户轨迹继续旋转；文字和图标始终正向。
- `COLLISION_RULE`：运行时根据放大后的星球直径重新计算安全距离，不以裁切或隐藏信息处理碰撞。
- `RESPONSIVE_RULE`：48rem 以下取消三轴巡航，切换为完整可读的静态项目列表；不得为了保留球体而制造横向滚动。
- `REDUCED_MOTION_RULE`：停止巡航、惯性和空间位移，保留静态深度层级和所有项目入口。
