# v3 独立浮岛与模块踏石

> 2026-09-29 更新：本版重新排列的盆景式群岛已被用户否定，停止以它作为视觉目标。当前设计样板见 `world-v4-disassembly.md`，严格回到原图整体构图；本版实现与测试仅作实验记录。

2026-09-29：用户明确否定连续网格的液态感，要求不同岛屿各自承载、各自漂浮，楼梯拆为独立小模块。本修订替代 v2 的连续网格运动规则；其他页面和手机接地校正继续沿用。

## 设计及素材合同

- 首页三秒信息：以人物与猫为中心，七个兴趣和创作区域共同组成一个有生活感的浮空群岛。
- 主焦点为中央人物；七座木屋/山丘通过可读标牌提供区域入口。正文、导航、标牌与热区由网页绘制。
- 每座区域岛使用一张完整透明插画：建筑、草地、岩体、植物是一体资产。中央地面与人物、猫共享同一刚性父节点，人物状态仍可单独切换。
- 七区沿用已确认外观、左上日光、蓝灰描边、暖木与绿植、分组叶丛和少量岩面明暗；不增加栏杆、绳桥或人物。
- 独立运动是用户要求的强制拆分边界：八个岛体及一枚重复使用的踏石素材。所有原生文件保留，WebP 只下采样，按约 2 纹素/逻辑单位统一输出，不能宣称 4K。
- 岛之间的天空留白是漂浮和运动安全间隙。踏石连接区域入口的方向，每一块完整、可见、独立；不切开旧画布补洞。
- 桌面世界仍使用 1600×1120 坐标系；手机纵向旅程及 440×410 人物画板保持现有构图，避免重引脚底/猫腹穿过岩壁。

## 运动合同

- 禁用地形顶点变形、缩放呼吸和连续波纹。岛体只作垂直平移，不旋转、不拉伸。
- 八岛使用不同周期、幅度和相位（约 7–13 秒，5–11 逻辑像素）。每个建筑、标牌、夜灯、物件都有明确所属岛，禁止按最近坐标猜测归属。
- 人物、猫和接触阴影同属 central；无论动作和漂浮相位，脚与地面相对关系不改变。
- 每条连接拆为多块短踏石，保留空隙。踏石以两端岛的高程为基准加小幅独立起伏；本体不变形。全周期检查安全间距。
- 清风暂停冻结当前岛和踏石；恢复不追赶经过的墙钟时间。减少动态效果首帧零位移、可继续使用全部按钮。
- 点击、拖动阈值、文件夹拖到电脑、焦点、相机恢复、昼夜、人物反馈和小物件保留。
