# 首页打开速度检查（2026-10-08）

范围：正式 `/` 首页，桌面 1440×900 与手机 390×844。使用本机 localhost 的无头 Chromium 测量；其 WebGL 渲染器为 SwiftShader。结果说明本机前后变化，不能外推为所有访客的加载时间。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 完整聚合图开始请求 | 约 450–520 ms | 约 85–120 ms |
| 世界可交互，桌面暖启动 | 约 1.3 s | 约 0.96 s |
| 世界可交互，手机暖启动 | 约 1.1–1.3 s | 约 0.96–0.98 s |
| 主线程长任务累计，桌面暖启动 | 约 700–800 ms | 约 330 ms |
| 展开后浏览器平均帧率（SwiftShader） | 约 47 FPS | 约 59 FPS |
| 展开后最慢 5% 帧间隔 | 33.4 ms | 16.8 ms |

调整：完整岛群与人物、猫先随 HTML 呈现；两个世界脚本并行下载；完整岛图转为保持可见像素一致的无损 WebP；八张岛图复用预先核对的透明边界；聚合图的点击遮罩由构建脚本生成，不再进入页面后逐像素读取；环境漂浮约 30 次/秒绘制，滚动、鼠标移动和聚焦时回到约 60 次/秒。渲染尺寸与各岛原始贴图尺寸未降低。

冷启动仍可能在首次创建 WebGL 上下文时产生较长任务；本机 SwiftShader 约 0.5 秒。若目标设备上仍感到明显停顿，应以该设备的性能录制决定是否增加 Canvas 2D 后备渲染器。

验证：`rigid-world.spec.ts` 六项通过；ESLint、TypeScript、Next 生产构建与点击遮罩校验通过。聚合、交接、展开画面见 `qa/world/opening-final/`。
