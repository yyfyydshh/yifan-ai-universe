## 构图契约

- 左侧姓名、定位、价值主张与 CTA 不变，是第一阅读区。
- 人物固定在右侧中心，不随项目公转漂移；默认 V4 低透明，探索时交叉淡入 V5。
- 五颗项目球以 72° 等相位占据同一条连续斜轨：上左、上右、左下、右下、下部各一个；共同相位偏移为人物安全区预留空间。
- 同一 Z 深度继续决定近大远小、透明度与人物前后层；脸部安全区只改变层级，不改坐标。
- 轨道背层、人物层、轨道前层保持现有拓扑；最多一颗球位于人物前景。
- 首页采用独立精选序号 `01–05`，第五颗显示为“05 / 专业 Skill · 文学去 AI 味”；进入作品宇宙和详情页后仍使用项目自身编号 `07`。

- 五颗球的可点击矩形不得相交，不得越出宇宙容器。

- 人脸椭圆区不得被前景项目球或高亮轨道覆盖。
- 48rem 以下转为五张静态纵向项目卡；不运行巡航、拖动或 Reveal。
- reduced-motion 保留完整五项目内容，停止巡航、惯性与 Reveal 跟随。
- v21 四项目实现保留为历史证据，不覆盖、不删除。
