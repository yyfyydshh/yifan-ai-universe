# 全球舆情分析项目视频 · v1 分镜审核稿

状态：`superseded by v2 / historical draft only`

## 内容与事实边界

- 目标：让招聘方在 25 秒内理解“Skill 接入任意 Agent 后，如何把公开信息转化为达到质量门槛的正式交付物”。
- 案例来源：用户提供的 `功夫女足-舆情分析报告.html` 与全球舆情分析 Skill 文档。
- 案例时点：2026-06-22—2026-07-26；用户输入仍使用“最近一月”，Agent 随后显式解析时间窗。
- 真实结果：102 条有效记录、14 个覆盖域名、5 类来源、正面与偏正面合计 87%、综合风险为低风险。
- 演示性质：脱敏真实案例；Agent 对话是界面化复刻，不伪装为实时录屏。
- API Key 永远只显示为 `op_••••••••`，不得出现在素材、日志或仓库中。
- 报告原文件不修改。最终视频使用真实页面截图；参考图中的报告外框只定义构图。

## 统一视觉指纹

- 主色：近黑 `#090B12`、炭黑 `#11141D`、暖白 `#E9E0D2`、焦点紫 `#A889E8`、暗紫 `#66528F`、通过绿 `#67C89A`。
- 字体角色：展示标题为 Noto Serif SC；正文为 Noto Sans SC；状态、编号和文件名为 IBM Plex Mono。
- 几何：细规则线、轻圆角、哑光表面；紫色只表达当前焦点，绿色只表达已经通过的真实门槛。
- 材质：低对比深空颗粒，不使用玻璃拟态、霓虹赛博、随机星球、Bento 或卡片墙。
- 动效原语：消息/文件位移、路径信号推进、状态交叉淡入；最终实现只使用可确定性回放的 transform 与 opacity。
