# v24 中文标题系统：参考图、素材裁决与执行 brief

## 已确认方向

- 视觉基线：`references/locked/v24/reference-cn-title-system.png`。
- 标题气质：技术编辑感；中文优先，无衬线主标题；衬线只用于姓名与极短展示词。
- 保持：深空色板、紫色技术标签、现有导航、人物素材、项目宇宙与所有真实内容。
- 不使用：超大中文宋体、超长口号式 H1、中文与英文在同一巨大标题中竞争。

## Render contract

| 区域 | 责任 | 标题规则 | 素材与边界 |
| --- | --- | --- | --- |
| 首页 | 个人身份首屏 | `杨逸凡` 保留衬线 display；其他中文内容维持正文层级 | 现有头像与项目宇宙不变；标题为 code-native |
| 一级页面 | 作品、经历、思考、关于我 | 2–6 字无衬线主标题，短观点为副标题 | C0 code-only；不新增图片 |
| 项目页 | 项目名称与工作台 | 中文项目名使用较收紧的无衬线 project title，标签与 tagline 分层 | C0 code-only；视频、poster 与项目事实不变 |
| 模块标题 | 工作台、能力系统、文章章节 | 无衬线 section title；不使用 display serif 承载长中文 | C0 code-only |

## 素材拆分清单

| 项目 | 判定 | 来源 | 状态 |
| --- | --- | --- |
| v24 标题参考图 | reference-only | ImageGen 参考图 | ready；不进入运行时页面 |
| 中文标题、标签、副标题 | code-native | CSS token + DOM 文案 | ready |
| 人物、星空、项目素材、视频 | 保持原样 | 已锁定 v23 / 用户提供资产 | 不改动 |

没有生成或替换任何运行时素材；所有标题与排版调整只修改 `tokens.css`、`app/globals.css` 和各页面的语义标题结构。

## 复刻执行 brief

- Builder：现有 Next.js / CSS 代码原生实现。
- 字体角色：`--font-display` 仅给姓名及极短展示；`--font-heading` 给全部中文页面与项目主标题；`--font-label` 继续给技术标签。
- 尺寸：中文一级标题 `clamp(2.6rem, 4.4vw, 4.8rem)`，项目标题 `clamp(2.25rem, 3.4vw, 4.15rem)`，行高 `1.12–1.16`，字距 `-0.025em` 至 `-0.035em`。
- 页面结构：H1 为简洁名称；观点句改为紧随其后的副标题；不更改可访问性层级。
- 响应式：小屏允许自然换行；禁止裁切、行数截断和水平溢出。
- QA：对首页、作品、经历、思考、关于我和七个项目页检查桌面、超宽、移动标题层级。
