# Execution Brief v9｜第二批项目

## 共享合同

- 继续使用 `ProjectCaseStudy` 判别联合类型和 `ProjectCaseStudyView` 路由，不在通用组件内堆叠 slug 条件。
- 新增三个独立客户端工作台组件；每个组件承担本项目独有状态机。
- 页面首屏先回答：服务对象、输入、角色、证据状态、最后得到什么。
- 桌面双栏自然等高；移动端解释面板跟随当前交互块，不复制整套流程。
- 视频槽保持 `DemoSlot` 的共创占位。

## 招投标

- 状态：输入路径、字段组、当前字段、当前流程阶段。
- 交互后果：字段依据、提取规则、留空条件、异常路径与交付门同步更新。
- 默认聚焦“招标金额”，最能体现语义边界而非简单字段映射。

## 热点快报

- 状态：快速/深度、当前筛选门、输出模式。
- 交互后果：查询射线、保留/排除理由、当前证据合同与输出说明同步更新。
- 所有候选项均为抽象信号，不出现真实新闻与运行计数。

## Humanizer

- 状态：恒稳/单篇、当前阶段、当前锁定对象、复核视角。
- 交互后果：保护范围、允许变化、停止条件与交付状态同步更新。
- 内容差异只展示抽象片段，强调“最小改动”而非生成文本效果。
