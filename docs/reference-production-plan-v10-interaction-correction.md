# v10 语义交互修正契约

日期：2026-08-16

## 触发原因

用户在生产预览中指出：热点快报的中心曲线没有可理解的交互含义，Humanizer 的静态修改对照也没有随选择产生可观察变化。两张 v9 参考因此对这两个 section 标记为 `reference-invalidated`；Tender Cleaner 和其余项目不受影响。

## 热点快报：七日证据筛选器

- THREE_SECOND_MESSAGE：匿名候选记录依次经过时间、字段、去重、来源与入选门，形成可追溯的短快报证据集合。
- SEMANTIC_GRAPHIC：候选按钮代表匿名记录；D-6 至 D0 是严格时间窗；记录状态代表当前规则门的机制判断；故事键用于解释去重。
- INTERACTION：切换检索模式、来源、日期、候选或阶段时，同一记录的状态、原因和当前证据字段同步变化。
- HONESTY：样例不含真实新闻标题或实时状态；绿色只表示机制规则通过。
- MOBILE：来源过滤、日期、候选、记录解释和阶段门单列重排，不隐藏排除原因。

## Humanizer：编辑提案审阅台

- THREE_SECOND_MESSAGE：每个编辑提案必须先证明没有触碰作者声音与叙事事实，才允许进入完整性审计。
- SEMANTIC_GRAPHIC：锁代表不可改变的内容；提案代表拟执行编辑；高亮代表改动或冲突；裁决代表机制边界。
- INTERACTION：选择删除解释性回声、改变叙事视角或强化结局后，原稿、拟改稿、当前保护项与允许/阻断结果同步变化。
- HONESTY：片段明确为抽象示例，不是真实作者文本；启发式风险分不表示 AI 比例或来源鉴定。
- MOBILE：锁定地图、提案、文本对照和裁决依语义顺序单列，不依赖动效才能理解。

## 共同验收

- 参考图与 QA 图必须使用不同的选择状态。
- 320、390、768、1280、1440、1920px 无水平溢出。
- 鼠标与键盘均能改变状态；`aria-pressed` 与可见内容一致。
- reduced-motion 下无空间位移，内容和裁决保持完整。
- ESLint 与 Next.js production build 通过。
