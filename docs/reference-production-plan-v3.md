# 参考图生成计划 v3 — 三轴作品宇宙

## 变更范围

本版本只重构首页与 `/work` 共用的项目宇宙交互，不改变导航、文案、项目数量、项目 URL、项目图标、色板、字体或移动端单列策略。Career 的焦点线修复不改变既有参考图拓扑，不纳入本次参考图重构。

## Style fingerprint

- 世界观：深空能力档案；空间关系表达项目可探索性，不表达社交匹配。
- 色彩：沿用 `design.md` 的近黑纸面、暖白文字、低饱和紫焦点；紫色仅用于当前/可操作状态。
- 字体：中文 serif display + sans body + mono evidence labels；所有标题保持 roman。
- Chrome：保留 `YY 杨逸凡`、现有导航密度、联系入口与细规则线。
- 几何：细描边、低对比空间网格、球体边界明确；不使用玻璃卡片墙、重型 WebGL 或随机粒子装饰。
- 动效语言：三轴巡航、用户定向惯性、状态 crossfade；每页不超过三种原语。

## Section render contract — Project universe v3

- `SECTION`: project-universe
- `RESPONSIBILITY`: 让访客通过一个可操控的三维项目空间选择正式案例。
- `THREE_SECOND_MESSAGE`: 这些项目不是目录卡片，而是一组可探索、可进入的 AI 能力成果。
- `PERSONAL_EVIDENCE`: 七个真实项目名称、分类、语义图标与既有项目 URL。
- `AUTHORED_MOVE`: 项目成为分布在同一三维能力球面上的语义节点；用户拖动改变旋转轴，系统随后沿该方向继续巡航。
- `PRIMARY_FOCAL_POINT`: 当前处于近景的项目节点。
- `SECONDARY_ANCHORS`: 左侧项目筛选；远近项目形成的深度轮廓。
- `READING_PATH`: 页面标题 -> 近景项目 -> 周围项目 -> 拖动/点击提示。
- `WHITESPACE_MAP`: 左上留白承载标题；球体边缘留白作为拖动跑道；底部留白承载操作提示。
- `SEMANTIC_GRAPHIC`: 球面位置表示同一作品集合中的浏览位置；z 深度只表达近远和当前可达性，不表达项目优劣；三组非共面弧线表达可沿多轴旋转，而非固定业务流程。
- `OVERLAP_LEDGER`: 远景节点可以被近景节点局部遮挡，但项目名称、图标和点击主体不得互相覆盖；移动端取消重叠。
- `EXCLUSION_ZONES`: 标题区、筛选区、每个项目文字/图标闭合区、导航区。
- `VIEWPORT_PAYLOAD`: desktop/ultrawide 首屏完整出现标题、至少一个近景项目、可辨识的远景轮廓和操作提示；48rem 以下完整单列七个项目，关闭三维位移。
- `ARCHETYPE`: C0 code-only；所有球体、空间环、图标、文字和交互都由代码实现，不新增生产 raster 素材。
- `TOPOLOGY`: section-specific；与 Career、项目详情观测台不共享定位结构。
- `PANEL_BUDGET`: 0 个独立图像 panel；最多一个当前项目的轻量焦点边界。
- `CODE_SAFE_AREA`: 全屏区域均为代码层；参考图只作为几何、层级和空间深度基线。
- `FORBIDDEN`: Soul 的匹配、头像、聊天、在线人数和社交语义；固定单椭圆；随机无规律漂移；靠缩放隐藏文字；不可点击的后景项目；虚构项目或指标。

## 交互契约

- 初始运动是确定性的三轴准周期巡航：主旋转轴稳定，叠加极小的轴向进动和节点呼吸，不使用逐帧随机数。
- 水平拖动主要改变 yaw，垂直拖动主要改变 pitch，对角拖动产生受限 roll。
- 松手后保留拖动产生的三维方向向量；惯性速度衰减到巡航速度后，继续沿同一方向旋转，不弹回预设轨道。
- 点击位移小于 6px 时进入项目；超过阈值只旋转，不触发链接。
- hover、focus、页面隐藏和离开视口时暂停；键盘左右控制 yaw、上下控制 pitch。
- reduced-motion 下停止巡航、惯性和空间位移，项目仍可完整点击和阅读。
