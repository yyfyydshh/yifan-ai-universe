# 原构图聚合与独立浮岛样板

2026-09-29。范围是 `public/world/island-disassembly.html` 的可交互设计样板。主站仍有实验中的 v3 渲染层；本文不宣称主站已经接入 v4，也不沿用 v2 的44项视觉验收。

## 用户纠正后的约束

- v3 重新排列的盆景式群岛已被用户否定，不能作为正式首页构图。
- 聚合态按用户原始连续岛屿构图，保留较宽中央草地和原场所关系。
- 原PNG下方已有裁断，先用内置 imagegen 补全左下长岩体、右侧瀑布水池及末端。输出为1309×1201透明PNG，属于补绘参考，不是原图像素完全不变的证明。
- 展开态保留中央与七区共8个主体，移除中间残草脊、散乱切片和断桥板。
- **最终交互以用户最新澄清为准：聚合时有台阶，展开后不保留连接，也不使用悬浮石阶。** 此前的83级浮阶与随后试用的苔藓浮石方案已取消。
- 岛体只做整体平移，不拉伸岩体，不做网格波浪；展开后分别按不同周期轻微升降。

## 样板实现

聚合与展开始终使用同一套8个不透明的完整岛体。旧的原图切片与补绘图交叉淡化已删除：实际慢放发现该方案在0.06–0.18出现明显切线和双影，不能因后半程正常就判整段通过。

完整补底参考图仅用于独立的“对照原图”开关，不参与运动。聚合构图依据原图相对位置重建，不宣称逐像素复原。

聚合时7段完整台阶共74级，仅用于连接相邻草台。展开进度0–0.18时从中部向两岸收起，至0.18完全隐藏；0.22之后岛体才开始分开。收拢按同一进度反向运行，先恢复聚合位置，再恢复台阶。展开态不显示连接、悬浮踏步或断桥残片。它不是“台阶连续变成漂浮组件”的实现，用户已取消该方向。

聚合时整体共享轻微升降，台阶与落点一起移动。展开后8座岛分别使用7.9–13.2秒周期，垂直幅度10–20逻辑像素，水平幅度2.5逻辑像素。放映室、工作室、游戏桌、思考区及杂物区的展开终点增加了间距，避免独立升降时轮廓相碰。

独立素材是用原图作编辑参考提取并补齐外轮廓，不能称为无损抠图。屋舍、草坪或岩面仍有生成差异。严格可见特征对齐只通过 work/stuff/thoughts；writing/music/games/films 超过2px残差门槛，central 匹配不足。样板采用人工核对的位置，未据此覆盖自动对齐失败记录。

工作室及思考区烘焙在素材中的灰石阶已单独清除，防止与动态踏步叠加。工作室清阶版发生约19源像素左移，已补偿约10.82逻辑像素。

所有主体使用完整图像边界计算取景，并在外侧加65逻辑像素余量；不能靠容器裁掉岩柱或瀑布来掩盖接缝。减少动态效果时立即切换状态，关闭漂浮；暂停按钮冻结岛体和阶梯。
