# 金融监管风险监测 · 天平交互版 · 2026-10-07

`/work/regulatory-risk` 以天平解释「消息要求能不能与企业条件对上」。主路径为：拿一张消息 → 放入左盘 → 看四项条件与天平变化 → 按需查看下一步。奶油纸色、木色、草绿、站立人物和奶牛猫沿用整站，没有大房间背景。

## 交互含义

左盘放消息，右盘代表企业画像。消息纸可直接点击，也可拖到左盘；拖到其他位置或取消不会切换消息。切换右盘企业后，同一条消息重新核对地域、主体、业务、时效。条件匹配时天平平衡；条件不符时倾斜；缺资料或草案未生效时保持待核实。倾斜仅示意条件未对齐，不是物理重量计算、风险评分或违法认定。

主页面展示五类去重演示消息：监管通知、处罚案例、草案、失效旧版、异地通知。每类有独立原文和理由。线上业务、仅线下、资料不全三个企业预设会改变业务条件。旧版已经失效或地域不符时，即使企业业务资料不足也保留明确的排除原因。

「回看这条原文」展示当前消息来源、时间、完整样本正文与处理理由。「看看下一步」只呈现刚放入的这一条消息，不直接展示整批报告。条件相符的监管通知给出控制核验行动；处罚案例只作为执法参考信号；草案与缺资料提示补证；不适用项留档。演示行动附负责人、建议安排和交付物，并绑定原文。建议时间不是监管法定期限。

工作群、邮件预览和防重复投递模拟收在下一步之后，非主路径必经操作。内存回执按消息、企业和渠道区分；待核实及不适用消息不进入模拟投递。所有资料均为固定虚构样本，不采集、不实际投递、不下载虚构正式报告。

人物随放入资料、阅读原文和查看行动改变姿态，猫可触摸。天平梁与吊盘使用同步旋转，吊盘保持水平；落点文字同步移动。减少动态模式立即呈现终态。主控支持键盘，原生对话框支持 Escape 与焦点恢复。
