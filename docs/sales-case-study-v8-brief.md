# 销售专业助手项目页 v8｜多轮转化分析 brief

状态：`reference-candidate`。本轮只重构 Sales Copilot 局部，不改变其他项目页。

## 访客与核心任务

- 主要访客：招聘方、AI 应用岗位负责人、销售运营与业务负责人。
- 三秒目标：知道这是一个读取客户多轮回答、持续刷新转化判断的 AI 销售专业助手。
- 十秒目标：看见同一个客户从第 1 轮到第 3 轮补充信息后，MQL 与五类销售结果怎样同步变化。
- 三十秒目标：理解判断来自累计对话，能回到客户原话；未知项不补造，案例与回复都保留人工核验边界。

## 已确认定位

> 面向销售与业务人员的 AI 销售专业助手。将客户的多轮回答持续交给 Agent，识别其所属行业、数据采集目标与自动化要求，累计刷新需求画像、MQL 等级、方案与落地链路、适用能力及回复引导建议，帮助团队更快理解需求并推进转化。

- 产品目标是提升转化推进效率，不宣称未经验证的转化率提升。
- 页面展示固定的脱敏机制示例，不是实时 Agent、真实客户记录或在线业务状态。
- MQL 仅展示公开简化依据，A 最高、D 最低，不公开内部权重。

## 主交互：三轮回复 → 当前转化状态

### 左侧：客户回答时间线

三轮不是三张独立卡片，而是一条累计上下文：

1. 第 1 轮：客户希望采集公开网页中的业务数据，目前主要靠人工整理。MQL D；先确认行业、业务目的和目标数据。
2. 第 2 轮：客户补充行业与业务场景，以及目标数据类型、字段、更新频率和希望减少的人工操作。MQL C；形成初步需求画像。
3. 第 3 轮：客户进一步明确希望打通采集、清洗、调度和交付，并评估与现有系统或 AI 分析的衔接。MQL B；形成需求确认—样例验证—方案评估—落地验收链路。

页面只展示经过抽象的需求维度与状态变化，不展示真实行业名称、站点、字段、数据量或内部 Skill 规则。

默认选择第三轮。轮次切换使用鼠标、触摸、方向键；切换后整套结果同步刷新。

### 中央：状态变化桥

- 显示累计轮次 `01 → 02 → 03` 与 MQL 轨迹 `D → C → B → A`。
- A 保持未达到，明确写出仍缺预算范围、决策链、数据合规边界和最终采购条件。
- 线只表示“累计上下文驱动本轮结果”，不作为装饰轨道。

### 右侧：转化状态快照

完整显示五类结果：

1. 需求画像（行业 / 业务目的 / 数据对象 / 自动化程度）
2. MQL 等级与变化原因
3. 方案方向与落地链路
4. 案例资料匹配
5. 回复引导建议

点击任一结果时：

- 左侧只高亮支撑判断的客户原话；
- 显示本轮新增事实、仍待确认项和相对上一轮的变化原因；
- 案例资料标记“从授权资料库筛选并由销售核验”；
- 回复标记“可编辑草稿”，不自动发送、报价或承诺实施。

## 三轮内容边界

### 第 1 轮｜MQL D

- 已知：客户存在公开网页数据采集需求，目前以人工整理为主。
- 输出：问题摘要、关键追问。
- 暂缓：完整需求画像、方案路由、案例匹配。
- 下一步：确认所属行业、业务目的、目标数据与来源范围。

### 第 2 轮｜MQL C

- 新增事实：行业与业务场景、目标数据类型、核心字段、更新频率、期望减少的人工操作。
- 输出：初步需求画像；采集与自动化程度方向；进一步确认来源可行性与交付方式。
- 仍未知：数据量、合规边界、现有系统衔接、预算与决策链。

### 第 3 轮｜MQL B

- 新增事实：希望打通采集—清洗—调度—交付，并评估现有系统或 AI 分析衔接；主动要求适用方案与授权案例类型。
- 输出：可公开的需求画像、B 级理由、需求确认—样例验证—方案评估—落地验收链路、授权材料类型、回复草稿。
- 仍未知：预算范围、决策人、数据合规边界和最终采购条件，因此不达到 A。

## 可靠性第二层

- 事实 / 假设 / 未知项严格分层。
- 主 Skill 按需编排画像、MQL、方案、案例和回复等子流程。
- 严格 JSON 契约确保每轮五类结果同步更新。
- 案例只从授权资料库选择，回复只生成草稿，销售负责核验与外发。
- MQL A—D、JSON 契约和子 Skill 编排为用户确认的内部项目事实；公开仓库仅承担脱敏概要证据。

## Hallmark 决策

- Audience：招聘方、AI 应用负责人、销售运营与业务负责人。
- Job：30 秒内理解“输入什么、如何累计、输出什么、为什么可靠”。
- Tone：技术但直观、克制、可信、面向转化决策。
- Macrostructure：`Turn-Led Conversion State Desk`，不复用 v7 的单轮问答结构。
- Typography：沿用全站暖象牙 serif 大标题、sans 正文、mono 证据标签。
- Color：深石墨底；低饱和紫只表示当前轮和可操作结果；绿色不表示假运行成功。
- Enrichment：无额外照片、插画或在线素材；页面本体全部代码原生。

## 禁止项

- 把三轮示例写成真实客户、实时 Agent 或线上运行状态。
- 第一轮提前生成完整画像、方案或案例。
- 用百分比、分数或转化率伪装量化效果。
- 把 D→C→B 写成真实客户成果。
- 公开内部 MQL 权重。
- 自动发送、自动报价、自动承诺实施。
- 用多个同权重卡片把累计关系打散。
