# Reference Production Plan v9｜第二批项目证据页

## 生成模式

- 采用 `C0`：纯代码实现；参考图只锁定布局、层级、交互状态与密度，不直接进入生产页面。
- 视觉继承 v7：深空黑底、暖白正文、克制紫色焦点、细线网格、中文宋体标题与无衬线界面文本。
- 三页共用“摘要 → 工作台 → 深度解释 → 边界/交付”的阅读骨架，但语义图完全不同。
- 每页最多三种动效：阶段推进、状态切换、一次性揭示；绿色仅表示规则通过，不表示真实运行结果。

## 01 招投标 29 字段语义炼制台

- 双入口：本地文件 / 已有八爪鱼任务。
- 主视觉：29 字段合同分组，不做 29 张重复卡；聚焦字段时显示原文依据、规则与留空边界。
- 路径：正文优先 → 字段提取 → 金额边界 → 去重 → 单条异常隔离 → CSV/JSON 一致性门。
- 关键边界：API Key 仅运行时使用；招标公告不推断中标结果。

## 02 热点快报七日证据雷达

- 模式切换：快速一批 / 深度六角度。
- 主视觉：七日时间环与候选信号进入证据筛选漏斗。
- 筛选门：标题、HTTP(S) URL、有效日期；规范链接、近似去重、来源分层、单域最多两条。
- 输出切换：新闻清单 / 决策简报 / 选题雷达 / 组合；明确只读机制演示，不做实时新闻流。

## 03 Humanizer 作者声音保护舱

- 范围门：文学文本通过，非文学文本停止。
- 模式切换：恒稳画像 / 单篇临时画像。
- 主视觉：原稿、内容锁、最小编辑差异与四角复核组成保护回路。
- 交付纪律：完整性优先于降分；风险分只作为启发式指标；最多三轮且另存新稿。

## 验收

- 一眼区分三种项目能力，而不是换标题的同构仪表盘。
- 交互结果必须对应真实规则、边界或交付物。
- 1280×900 桌面基准下不依赖横向滚动；移动端改为顺序叙事。
- 不出现客户数据、实时状态、伪造指标或未标记示例。
